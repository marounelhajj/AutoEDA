Data Preprocessing
==================

Overview
--------

The preprocessing module prepares raw datasets for analysis.

Missing Values
--------------

Supported methods:

* Drop rows
* Drop columns
* Mean imputation
* Median imputation
* Mode imputation

Encoding
--------

* Label Encoding
* One-Hot Encoding

Scaling
-------

* StandardScaler
* MinMaxScaler

Outlier Treatment
-----------------

AutoEDA provides:

* Outlier detection using IQR
* Outlier removal
* Outlier transformation using median replacement
