User Guide
==========

Step 1: Upload Dataset
----------------------

Click the Upload Dataset button and select a CSV file.

Step 2: Explore Data
--------------------

Review dataset statistics and visualizations.

Step 3: Analyze Feature Stability
---------------------------------

Navigate to the Feature Stability page.

Step 4: Apply Preprocessing
---------------------------

Select preprocessing operations and apply them.

Step 5: Download Results
------------------------

Export the processed dataset.
